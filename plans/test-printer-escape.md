# 外へ出ていく文字と置き場に試験を足す

店舗も客も自由に打てる文字が、そのままプリンタへ流れる。画像は画面が決めた置き場へ
書かれ、別の仕組みがそこを見張って縮小する。どちらも**ずれても落ちない**ので、
ずれたことに気づけない。

## レシートに出す文字の逃がし処理

`escapePrinterString`（`functions/src/functions/express/receiptFormat.ts`）は、
receiptline の記法に使われる文字を落とす。商品名や客の名前にそれが混ざると、
そこから先が罫線や書式として解釈され、レシートの体裁が崩れる。

留めたもの:

- 記法の文字を一つずつ、そして続いたときに落とすこと
- 行を割る記法を名前に仕込まれても行が増えないこと
- 全角の符号は記法ではないので残すこと
- 改行とタブには触らないこと（行を組み立てる側の仕事）

## 画像の置き場

縮小の処理は Cloud Storage の置き場に当てた型で呼ばれる
（`functions/src/functions/image/constant.ts`）。型が画面の書き込み先とずれると、
**縮小が一度も走らないまま原寸が配られる**。

留めたもの:

- 型が、表紙・店舗の写真・商品の写真をそれぞれ拾い、互いを取り違えないこと
- `*` が階層を跨がないこと（跨ぐと別の店舗の下まで当たる）
- **画面が組み立てている書き込み先と、型が一致していること**

最後のひとつが本題。画面側は `.vue` の中なので読み込めない。ファイルを読んで、
組み立てている文字列そのものを取り出して照らしている。型を一段浅くして、この試験が
赤くなることを確かめた。

## 確かめ方

`yarn test` と `cd functions && yarn ci_test` が緑。実装には触れていない。
