# メニュー編集: オプションをドラッグで並べ替えられるようにする

omochikaeri-docs#179

## 背景

`src/app/admin/Restaurants/MenuItemPage.vue` のオプション編集は各行の ↑ / ↓ ボタンで1つずつ動かす形で、
オプションの多い商品では下から上へ運ぶのに何度も押すことになる、という店舗オーナーからの要望。

商品一覧の並べ替え（omochikaeri-docs#164、`MenuListPage.vue`）で `vuedraggable` を導入済みなので、依存の追加は無い。

## 方針

商品一覧と同じ**「並べ替えモード」**にする。

- 普段の見た目は今のまま（↑↓ボタン・入力欄・プレビュー）
- 「ドラッグで並び替え」を押すとモードに入り、行はつまんで動かすだけの簡素な表示になる
- もう一度押すと元に戻る

商品一覧もモード中は編集欄を隠す作りなので、操作が揃う。

### 並べ替えモードのあいだだけ通し番号を持つ

`vuedraggable` は各行に一意の目印（`item-key`）を要求する。商品一覧はそれが Firestore の文書 ID
だったので問題にならなかったが、**オプションは店舗オーナーが打った文字列そのもの**なので、

- 「追加」を2回押して空のオプションが2つ並ぶ
- 同じ名前のオプションが2つある

のときに目印が重複し、ドラッグが別の行を動かす。

そこで、モードに入った時点で `menuInfo.itemOptionCheckbox` から `{ id, text }` の配列を組み立て、
`id` を目印に使う。`id` はモードを抜ければ消える。保存もされず Firestore にも出ない。
**モード中は入力欄を出さない**ので、番号と中身がずれる隙が無い。

### 並べ替えた結果はその場で `menuInfo` に書き戻す

モードを抜けるときにまとめて書き戻すのではなく、ドラッグのたびに
`menuInfo.itemOptionCheckbox` を更新する。モードに入ったまま「保存」を押しても
並べ替えた順序が保存されるようにするため。

### 保存のタイミングは変えない

この画面は他の項目も「保存」ボタンまで確定しない作りなので、並べ替えも揃える。
商品一覧のような即保存はしない（＝並べ替えて保存せずに離れれば元に戻る）。

## 変更するもの

- `src/app/admin/Restaurants/MenuItemPage.vue`
  - `vuedraggable` の読み込み
  - 並べ替えモードの状態と、モード中の行の配列
  - 「ドラッグで並び替え」ボタン（オプションが2つ以上あるときだけ出す）
  - モード中の表示（つまむ取っ手 + オプションの文字）

既存の行の表示（↑↓・入力欄・削除・プレビュー）には手を入れない。

i18n の `editMenu.reorder` / `editMenu.doneReorder` は omochikaeri-docs#164 で追加済みのものを使う。

## 確認すること

- 並べ替えたあと保存し、リロードしても順序が残る
- 保存せずに離れると順序が戻る
- 空のオプションが2つ並んだ状態でも、つまんだ行だけが動く
- オプションが1つのときはボタンが出ない
- 注文画面でのオプションの表示順が、並べ替えた順になる
- スマホで操作できる
