# メニュー編集: オプションプレビューの開閉

omochikaeri-docs#179 の残り（ownplate#1820 でドラッグ並べ替えを入れた分の続き）

## 背景

オプション1行ごとに、その下へプレビューの箱が出っぱなし（`MenuItemPage.vue`）。選択肢の多い商品だと
画面が縦に伸びて、並べ替えそのものがやりづらい。

## 方針

- 置き場所は「オプション」の見出しの下、並べ替えボタンの隣
- **出す条件は「中身のあるオプションが1つ以上あるとき」**。空しか無ければプレビューに映すものが
  無いので、トグルも出さない
- 状態は `adminConfigs/{uid}`（`src/utils/admin/Toggle.ts` の `useAdminConfigToggle`）。管理トップの
  `simpleMode`、注文一覧の `queryIsPlacedDate` と同じ仕組みで、**店舗や商品に依らずアカウントごとに1つ**。
  端末を変えても引き継がれる
- **既定はプレビューを出す（いまの見た目のまま）。** `useAdminConfigToggle` は `defaultValue` に
  関わらず初期値が `ref(true)` で、Firestore の応答が返ってから本当の値に置き換わる。既定を
  「隠す」にすると全員が「出てから消える」を見るので、既定は「出す」が正しい。
  **ただし、隠すことを選んだ人は開くたびに一瞬プレビューを見る。** 消すには共通の composable に
  「まだ読み込んでいない」を表す状態が要るので、その共通部分を触らない今回は残す

## 確認すること

- プレビューを隠した状態で画面を離れ、別の商品を開いてもそのまま隠れている
- 別の端末でログインしても、隠した状態が引き継がれている
- オプションが1つも設定されていない商品では、トグルが出ない
- 隠した状態で開き直したときのちらつきが許容範囲か（一瞬出てから消える）
- 並べ替えモード中はプレビューも出ない（いまと同じ）
