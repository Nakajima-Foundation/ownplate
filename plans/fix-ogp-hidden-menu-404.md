# 無いメニュー・非公開・削除済みのメニューの URL は OGP ページで 404 にする（#2072）

## 問題

`ogpPage` は、メニューが非公開・削除済み・未検証でも、名前・画像・説明を title と meta に出していた。

## 直し方

- `getMenuData()` の直後に、お客様の画面と同じ条件（`isPublicMenu`）で判定する
- メニュー ID が付いていて、そのメニューが無いか見えないなら、他の 404 と同じく SPA のひな形を 404 で返す
- 構造化データ側の同じ判定は、この 404 と重なるので外す

- `tests/express_test.ts` の試験用メニューに `publicFlag` / `deletedFlag` を足す（本物のメニューは必ず持っている）
