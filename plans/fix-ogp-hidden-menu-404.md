# 非公開・削除済みのメニューの URL は OGP ページで 404 にする（#2072）

## 問題

`ogpPage` は、メニューが非公開・削除済み・未検証でも、名前・画像・説明を title と meta に出していた。

## 直し方

- `getMenuData()` の直後に、お客様の画面と同じ条件（`isPublicMenu`）で判定する
- 見えないメニューなら、他の 404 と同じく SPA のひな形を 404 で返す
- 構造化データ側の同じ判定は、この 404 と重なるので外す

## 変えないもの

- 存在しないメニュー ID の URL は、これまでどおりお店のページとして返す
