## v4.1.0 (2026/10/23)

店舗向けの通知に Web Push を追加しました。管理画面をホーム画面に追加しておくと、
画面を閉じていても新しい注文やキャンセルが端末に届きます。

- 管理系
  - Web Push で通知を受け取れるようになりました
    - 「通知設定」から端末ごとに ON / OFF します。店舗オーナーと、その店舗を担当するサブアカウントの両方に届きます
    - iPhone / iPad は iOS 16.4 以降で、「ホーム画面に追加」した状態でのみ利用できます
    - 招待用の URL から、普段使う端末を登録できます
    - 飲食店向けの LINE 通知と電話通知は、今後 Web Push 通知に統合される予定です。お早めに Web Push 通知への移行をお願いします
  - 店舗設定に「祝日を定休日にする」を追加しました。対象の祝日は翌年末まで一覧で確認できます
  - メニューごとに「祝日は受け取れません」を設定できるようにしました
  - メニューのオプションをドラッグで並べ替えられるようにしました
  - 5MB を超える画像は、送信する前に理由を表示するようにしました

- ユーザー系
  - 祝日を定休日にしている店舗では、祝日を受け取り日に選べないようになりました

- 共通
  - 画面に表示する日時を日本時間に統一しました（注文日時、受け取り予定、注文履歴、管理画面の注文一覧・注文詳細）
